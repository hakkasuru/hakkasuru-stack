# Write LinkedIn Hook

Write a compelling opening line (hook) for a LinkedIn post.

A great LinkedIn hook should:
- Be 1-2 sentences max
- Create curiosity or make a bold statement
- Speak directly to the target audience
- Avoid generic openers like "I'm excited to share..."

## Instructions

Given a topic or draft post, generate 3-5 hook variations. For each:
- Lead with the strongest idea
- Use plain, conversational language
- End with a pattern interrupt or open loop that makes the reader want to continue
